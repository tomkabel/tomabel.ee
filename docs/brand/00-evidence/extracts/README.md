# extracts/ — curated quotable passages

Two layers, deliberately separated:

| Layer | Path | What it is |
|---|---|---|
| Raw captures | `../raw/` | Full fetched pages and artefacts, as received. `raw/github/` holds the READMEs; `raw/linkedin-profile-2026-10-24.md` the profile; the search and voice-stat JSON. |
| Raw press | `../raw/press/` | Third-party press pages. **Gitignored, local only** — they are copyrighted and are not redistributed. Re-fetch from the URLs in `press-2024-2026.md`. |
| Extracts | `extracts/` | The passages that may be quoted in brand outputs, each tagged with the claim status and the theme code from `../statements-and-quotes.md`. |

**Rule.** A passage may be quoted from `extracts/` only. If it is not here, the source counts as
unread for quoting purposes, even if a raw capture exists. When in doubt, re-read the raw file and
add the passage here rather than paraphrasing from memory.

  Postimees [S-10], Äritehnoloogia [S-11], Geenius [S-12]) with the publicly served text verbatim,
  and paywall boundaries marked.
- `S-21-ai-answer.md` — the AI-answer perception snapshot, verbatim, with the exact query string.
